# Audio Streams

Build @VERSION@, source @SOURCE_COMMIT@. FTP the contents of sd-card/ to the SD root in binary mode, close FTP, then launch CTR2WUP Audio Streams in Aroma with TV and GamePad volume audible.

Follow the on-screen listening prompts: A plays, R confirms correct sound, L records a problem, ZL skips and ZR advances with a problem. Use X for pause/resume and Plus for a new session when prompted. Reference WAVs are in reference/. Press Minus to exit and check for silence.

FTP the whole sd:/ctr2wup/results/ folder to the computer, ZIP it and return it with a brief sound/exit observation. Include failed or incomplete runs; do not select individual logs or add games, saves or keys.
