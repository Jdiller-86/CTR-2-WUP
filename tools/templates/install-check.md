# Install check

Use WUP Installer GX2 under Aroma with signature patches (01_sigpatches.rpx). FTP the contents of sd-card/ to the SD root in binary mode, preserve existing files, then close FTP. Install CTR2WUP-M1 to the usual system-memory or USB target; stop if the supplied title ID belongs to another application.

Launch the installed title twice from Wii U Menu. On each launch, check both screens, press Minus and confirm return to Menu. The app checks SD recovery automatically; no controls tour or stability countdown is required.

After exiting, FTP the whole sd:/ctr2wup/install-check/ folder to the computer, ZIP it and attach it with a short installation/screen/exit observation. Include partial failures and the exact installer error if present. Source, checksums and notices are under support/.
