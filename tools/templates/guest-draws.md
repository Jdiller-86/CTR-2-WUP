# Guest Draws

Build `@VERSION@` · source `@SOURCE_COMMIT@`.
Use this kit only when a changed rendering path needs console verification.
A new build alone does not require another run.

1. FTP `sd-card/` contents to the SD root in binary mode. Preserve existing
   files, close FTP and launch **CTR2WUP Guest Draws** in Aroma.
2. Wait for the red/green diagonal scene on **both** screens; the initial image
   is startup output. Compare with the kit's `images/` pictures. At the picture
   prompt, **R** confirms correct output and **L** records a problem.
3. The original guest checks its pixels and exits automatically. If prompted,
   press **Plus** to run it again and wait for the new scene and PASS/exit.
   Press **Minus** after the guide completes and note the return outcome.
4. After closing the app, FTP the whole `sd:/ctr2wup/results/` folder to your computer,
   ZIP it and return that ZIP. Do not select or pair individual logs. Reports
   record the source identity; include partial failures.

Add a short note about both pictures, restart and Minus return. If it remains
at WAIT for about three minutes, use **ZR** to record the problem and Minus if
responsive; do not repeat a hung run. No PC command is required. Do not add games or keys. This bounded software-rendered fixture
does not prove general PICA behavior, game compatibility or useful game speed.
