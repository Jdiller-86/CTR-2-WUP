# Guest Draws

Build @VERSION@, source @SOURCE_COMMIT@. FTP the contents of sd-card/ to the SD root in binary mode, close FTP and launch CTR2WUP Guest Draws in Aroma.

Wait for the red/green diagonal scene on both screens and compare with images/. At the picture prompt, R confirms correct output and L records a problem. Complete the requested on-screen steps; use Plus for restart when prompted and Minus to exit. If WAIT lasts about three minutes, use ZR to record the problem, then Minus if responsive.

FTP the whole sd:/ctr2wup/results/ folder to the computer, ZIP it and return it with a brief picture/restart/exit observation. Include partial failures. Keep games, saves and keys out of the return.
