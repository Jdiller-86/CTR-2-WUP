# Textured Guest

Build @VERSION@, source @SOURCE_COMMIT@. This app exercises new guest texture sampling and TEV through GX2. Move any existing sd:/ctr2wup/results/ folder aside, FTP sd-card/ contents to the SD root in binary mode, close FTP and launch CTR2WUP Textured Guest in Aroma.

Compare both screens with images/: one diagonal half has a striped colored pattern with cutouts; the other is pale green from a bilinear combiner chain and additive blending. R confirms the pictures and L records a problem. Wait for the automatic GPU readback result, then press Minus to exit; keep partial results if the app stops responding.

FTP the whole sd:/ctr2wup/results/ folder to the computer, ZIP it and return it with a brief picture/exit observation. Keep games, saves and keys out of the return.
