# Scene Check

Build @VERSION@, source @SOURCE_COMMIT@. FTP the contents of sd-card/ to the SD root in binary mode, close FTP and launch CTR2WUP Scene Check in Aroma.

Compare the displayed scenes with images/. Use R for correct output, L for a problem and the on-screen controls for the requested restart check. Press Minus to exit; preserve any automatic failure shown by the app.

FTP the whole sd:/ctr2wup/results/ folder to the computer, ZIP it and return it with a brief picture/exit observation. Include partial failures. Keep games, saves and keys out of the return.
