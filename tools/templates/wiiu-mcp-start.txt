CTR2WUP Wii U MCP starter kit @VERSION@
Source: @SOURCE_COMMIT@. Hardware acceptance is pending.

Windows x64: choose Extract All, then double-click Install Wii U MCP.exe.
Click Install & continue, select your SD card when available, and enter the
Wii U IP in Connect Codex. Save the connection, then restart Codex. Python and
the bridge dependencies are included; no terminal commands or manual settings
editing are needed. Installation is per-user and adds a Start menu shortcut.
You can skip the SD card and connection steps until you're home.

The SD step requires an existing Aroma installation. Keep the console powered
off while the card is removed. Check the preview, then click Back up & copy
files; changed originals are backed up before replacement and copied files
are verified. Games and saves are left in place. Restart Aroma with the card,
enable FTPiiU and wiiload, and leave system-file access disabled. Find the Wii U
IP in FTPiiU settings. Test connection checks FTPiiU without launching an app.

Other platforms: install Python 3.12+ and run python installer.py for the same
wizard, or use python setup.py --console YOUR_WII_U_IP. The portable kit needs
Internet for its initial dependency installation. Native rebuilds require a Git
checkout and the verified SDK; the included original diagnostic can be launched
without a compiler. Cloud access also needs a secure route to the companion
computer and MCP registration. See docs/wiiu-mcp.md in source.zip for details.
