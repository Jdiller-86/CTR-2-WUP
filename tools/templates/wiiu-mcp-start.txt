CTR2WUP Wii U MCP starter kit @VERSION@
Source commit @SOURCE_COMMIT@. Physical-console validation is pending.

Install Python 3.12+ on a computer on the Wii U's LAN and extract this ZIP to a
permanent folder. Open a terminal there and run the command with your Wii U's IP.

    python setup.py --console 192.168.1.50

Setup verifies the kit, installs pinned Python dependencies over the Internet
and generates local/mcp-server.toml and local/ctr2wup-control.pub. The bundled
source snapshot is the default project. Use --project with a Git checkout and
the verified devkitPro SDK for native rebuilds.

While the Wii U is off, copy the required files from sd-card/ to the SD root
of your existing Aroma installation. Compare versions before replacing Aroma
modules or plugins. Copy local/ctr2wup-control.pub to wiiu/ on the SD card.
Keep the private key on the companion computer. Boot Aroma and enable FTPiiU
and CTR2WUP Control. Leave FTPiiU system-file access disabled.

Add the entry from local/mcp-server.toml to your MCP client configuration
and restart the client. Start with wiiu_console_state. For a first launch, pass
artifacts/wiiu-mcp-starter/ctr2wup-prototype.wuhb to wiiu_launch. See
docs/wiiu-mcp.md in source.zip for console receipts, WUP installs and reboot.
