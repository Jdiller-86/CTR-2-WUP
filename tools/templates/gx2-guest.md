# GX2 Guest

Build @VERSION@, source @SOURCE_COMMIT@. This app exercises compiled guest draws through GX2. Move any existing sd:/ctr2wup/results/ folder aside, FTP sd-card/ contents to the SD root in binary mode, close FTP and launch CTR2WUP GX2 Guest in Aroma.

Compare both screens with images/; R confirms correct rectangles and L records a picture problem. Wait for the automatic guest readback result, then press Minus to exit. Include partial results if the app stops responding.

FTP the whole sd:/ctr2wup/results/ folder to the computer, ZIP it and return it with a brief picture/exit observation. Keep games, saves and keys out of the return.
